# Офлайн-калькулятор рассрочки «Эко Сити Айни» — инструкция

Папка `docs` — готовое офлайн-приложение (PWA): калькулятор, КП, справочник квартир.
После первой загрузки работает без интернета и ставится на экран телефона как приложение.

Состав папки:

| Файл | Что это |
|---|---|
| `index.html` | Калькулятор целиком: расчёт, дизайн, КП |
| `apartments.js` | Справочник квартир (240 шт.) + параметры: цена $/м² по умолчанию, порог хвоста, менеджеры |
| `manifest.json` | Паспорт приложения (имя, иконка, цвета) |
| `sw.js` | Офлайн-кэш; при обновлениях поднимать `CACHE_VERSION` |
| `icon-192.png`, `icon-512.png`, `icon-180.png` | Иконки |

Важно: приложение считает **предварительный расчёт**. Наличие и статус квартиры
проверяются только по основной системе — расчёт не является бронью.

## 1. Публикация на GitHub Pages

Нужен бесплатный аккаунт на [github.com](https://github.com).

1. **Создайте репозиторий**: справа вверху «+» → *New repository* → имя, например
   `eco-city-calc` → Public → *Create repository*.
2. **Загрузите папку docs**: в репозитории *uploading an existing file* (или
   *Add file → Upload files*) → перетащите **саму папку `docs`** в окно →
   внизу *Commit changes*.
   Должно получиться: в корне репозитория лежит папка `docs`, а в ней `index.html`.
3. **Включите Pages**: *Settings* → слева *Pages* → раздел **Build and deployment**:
   - *Source*: `Deploy from a branch`;
   - *Branch*: `main`, папка `/docs` → *Save*.
4. Через 1–2 минуты вверху страницы Pages появится адрес вида:

   `https://ВАШ_ЛОГИН.github.io/eco-city-calc/`

   Это и есть ссылка для менеджеров. Откройте её и проверьте расчёт.

> Альтернатива через командную строку (git уже установлен):
> ```
> cd "C:\Users\User\Desktop\Рабочая папка\Эра констракшн\Eco City Aini"
> git init
> git add docs
> git commit -m "Офлайн-калькулятор"
> git branch -M main
> git remote add origin https://github.com/ВАШ_ЛОГИН/eco-city-calc.git
> git push -u origin main
> ```
> Затем шаг 3 (включить Pages) — так же через сайт.

## 2. Установка на телефон

Сначала откройте ссылку Pages в браузере телефона — при первом открытии
приложение закэшируется и дальше работает без интернета.

### iPhone (Safari)

1. Откройте ссылку в **Safari** (не в Chrome и не из WhatsApp — там нет установки).
2. Кнопка «Поделиться» (квадрат со стрелкой вверх, внизу по центру).
3. В списке — **«На экран "Домой"» / "Add to Home Screen"**.
4. *Добавить*. На экране появится зелёная иконка «Эко Сити Айни».

### Android (Chrome)

1. Откройте ссылку в **Chrome**.
2. Меню ⋮ (справа вверху) → **«Добавить на главный экран»** /
   **«Установить приложение»** (иногда Chrome сам предлагает установку плашкой снизу).
3. Подтвердите. Иконка появится на рабочем столе.

Проверка офлайна: включите авиарежим и откройте приложение с иконки —
калькулятор должен работать полностью.

## 3. Обновление справочника квартир

Справочник — один файл `apartments.js`. Обновление = замена этого файла.

1. Подготовьте новый список квартир из основной системы (лист «Объекты»,
   только тип «Квартира»): код, подъезд, этаж, №, комнат, площадь.
   Цены, статусы и брони в файл **не вносятся** — намеренно.
2. Впишите квартиры в `apartments.js` в том же формате:
   ```js
   { code: "Эт02-Кв001", entrance: 1, floor: 2, num: "1", rooms: 2, area: 78.1 },
   ```
3. Поставьте новую дату в `generatedAt` — она видна менеджерам под выбором квартиры.
4. Замените файл в репозитории: GitHub → папка `docs` → `apartments.js` →
   карандаш (правка прямо на сайте) или *Upload files* с заменой → *Commit changes*.
5. **Обязательно**: в файле `sw.js` увеличьте число `CACHE_VERSION` (1 → 2 → 3…)
   и закоммитьте — иначе телефоны продолжат показывать старый кэш.

Телефоны подтянут обновление при первом открытии приложения с интернетом
(иногда со второго открытия — так устроено обновление PWA).

## 4. Обновление цены по умолчанию и параметров

Всё в том же `apartments.js`, блок `params`:

```js
params: {
  basePrice: 1500,      // цена $/м² по умолчанию (в калькуляторе редактируема)
  tailLimitPct: 30,     // порог финального платежа («хвоста»), % от стоимости
  managers: ["Айдана", "Орозгуль", "Рустам", "Алмаз"]   // подсказки в поле «Менеджер»
},
```

- `basePrice` — подставляется в поле «Цена м², $» при открытии; менеджер может
  менять цену в самом калькуляторе, это только значение по умолчанию.
- `tailLimitPct` — при финальном платеже больше этого процента от стоимости
  калькулятор показывает предупреждение.
- `managers` — выпадающие подсказки в поле «Менеджер» на КП.

После правки — тот же шаг 5: поднять `CACHE_VERSION` в `sw.js`.

## Частые вопросы

**Открыл(а) файл index.html двойным щелчком с диска — установка не предлагается.**
Так и должно быть: установка и офлайн-кэш работают только по ссылке с сервера
(GitHub Pages). Сам расчёт при открытии с диска тоже работает.

**Обновил(а) справочник, а на телефоне старые данные.**
Проверьте, что подняли `CACHE_VERSION` в `sw.js`. Затем откройте приложение
с интернетом, закройте полностью и откройте ещё раз.

**Как убрать приложение с телефона.**
Как обычное приложение: долгое нажатие на иконку → удалить.
